🌍 Country Info App

A sleek, dark-themed Python GUI desktop application built with PyQt5. It securely hooks into the RestCountries API to pull real-time demographic, economic, and regional metadata for any country globally.

🚀 How to Run this Application Locally

Ensure you have Python 3 installed on your machine, then run these steps in your command line terminal:

  1. Clone this repository: 
    git clone https://github.com
  2. Navigate into the project folder: 
    cd YOUR_REPO_NAME
  3. Install the required dependencies: 
    pip install -r requirements.txt
  4. Launch the app: 
    python countries.py
